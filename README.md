# ☦ Orthodox Codex — مدوّنة التراث الأرثوذكسي

مستودع مفتوح متعدد اللغات البرمجية لتوثيق وعرض الدراسات والتراث الكنسي المسيحي الأرثوذكسي عبر صفحات ويب وتطبيقات تفاعلية.

🌐 **الموقع المباشر:** `https://<username>.github.io/orthodox-codex/`

## الأهداف

1. توثيق الدراسات الكنسية بمصادرها (آباء، مخطوطات، سنكسار) بدقة قابلة للمراجعة.
2. عرضها كصفحات تفاعلية سريعة، متجاوبة، وتعمل بدون خادم (Static).
3. إتاحة الشفرة المصدرية للجميع للمشاركة والتصحيح (Open Source).

## الهيكل

```
orthodox-codex/
├── index.html                        # البوابة الرئيسية وفهرس الموضوعات
├── README.md                         # هذا الدليل
├── .gitignore                        # استبعاد Web / Node.js / Python
└── topics/
    └── gospel-of-matthew/
        └── index.html                # القديس متى العشّار وإنجيله (تفاعلي)
```

كل موضوع = مجلد مستقل داخل `topics/` فيه `index.html` ذاتي الاعتماد، فيمكن إضافة موضوع بدون المساس بالباقي.

## التقنيات

- HTML5 دلالي + Tailwind CSS (CDN) + Lucide Icons + خط Cairo
- اتجاه RTL كامل، تصميم داكن، متجاوب (Mobile-first)
- Web Speech API لنطق الأسماء بعدة لغات (يعتمد على الأصوات المثبتة في جهاز المستخدم)

## التشغيل محلياً

لا يحتاج بناء. افتح `index.html` في المتصفح، أو شغّل خادماً بسيطاً:

```bash
python3 -m http.server 8000
```
